## 1. 레퍼런스와 가져온 장치

| 레퍼런스 | 확인한 내용 | 가져온 장치 | 첫 삽 어디에 | 확인한 곳 |
|---|---|---|---|---|
| **Site Coach: Start Smart** (Simcoach Games, 2017) | 현장을 둘러보며 위험을 찾는 무료 게임. 현장 3곳, 한 번 할 때마다 20여 개 문제가 무작위로 나옴, 배지. 떨어짐·맞음·보호구 잘못 사용·굴착·사다리·비계 등. "정식 교육을 대신하지 않음" | 장면 속 위험 찾기, **무작위 출제**, 배지 | 장면 0~6 위험 찾기(`openScene`), 다시 할 때 위험 순서·일부를 섞음, 별·계급·도감 | [App Store](https://apps.apple.com/us/app/id1312987429), [Construction Dive](https://www.constructiondive.com/news/leveling-up-recruiting-and-safety-with-gaming-apps/565148/) |
| **Harness Hero** (Simcoach Games + 서부 펜실베이니아 건설협회, 2016) | 추락 방지 장치를 직접 고르는 게임: 걸 곳, 고정 장치, 안전대 입는 법, 연결 고리. 업계 안전 전문가 자문. 게임 확인서는 "실제 능력과 무관"하다고 밝힘 | 보호구 **입혀보기·걸 곳 고르기** 체험 | 기초 레슨 3 "보호구" 입혀보기 활동(v11), 장면 1·2 "고리를 걸어요" 비교 그림. (3단계) 안전대 고리 걸기·손상 장비 찾기 | [MBA 서부 펜실베이니아](https://mbawpa.org/safety/safety-games), [GBCA](https://gbca.com/safety/harness-hero-video-game-can-help-save-lives/) |
| **HazApp** (CM Labs, NCCER 협력, 2021) | 가상 현장에서 위험을 찾고 **가장 좋은 해결책을 고름**. 사고 유형별 4개 장. "공식 교육을 대신하거나 자격을 주지 않음". 2025년 이후 App Store에서 내려간 것으로 보이는 기록 있음 | **찾기 → 어떻게 할까** 2단계, 사고 유형별 묶음 | 장면에서 위험을 다 찾으면 "어떻게 할까?" 그림 3장 중 고르기(멈춰요·알려요·보호구), 위험 종류 아이콘(떨어짐·맞음·끼임…)으로 도감 | [App Store](https://apps.apple.com/us/app/hazapp/id1588917954?l=pt-BR), [SHP](https://www.shponline.co.uk/safety-management/apps-site-hazards-inspections/) |
| **서울시 외국인 건설근로자 무번역 그림책** (Silent Book, 2020) | 통번역 없이 그림만, "지켰을 때 / 안 지켰을 때" 비교, 5개 분야 73건 | **글 없는 두 장 비교** | 위험을 찾으면 "위험한 모습 ✕ → 안전한 모습 ✓" 두 장, 그림 점검(안전한 쪽 고르기) | 서울시 건설알림 안전자료방. 공공누리 4유형(변경 금지) → **그림은 쓰지 않고 방식만** |
| **고용노동부·안전보건공단 외국인 근로자용 안전보건 픽토그램** (2024~) | 외국인이 그림만으로 위험을 알게 하는 현장 부착 픽토그램 | 위험 표시 그림 체계, **표지 색·모양 규칙** | 위험 종류 아이콘 11종을 경고 표지(노랑 삼각형) 안에 **직접 그림** | 원본 파일·공공누리 유형 **미확인**(바탕 화면 `첫삽` 폴더에 파일 없음) → 파일은 쓰지 않음 |
| **Duolingo** (학습 앱 설계 관행) | 길을 따라 하나씩 열리는 단계, 연속 학습일, 캐릭터 | 지도 진행, 연속 출근, 캐릭터 | 현장 지도(건물 한 동, 0층→6층→지붕), 상단 "연속 n일", 삽이(표정만, 그림 모드) | 일반 설계 관행 — 사실 근거 아님 |
| **Brilliant** (학습 앱 설계 관행) | 화면 하나에 질문 하나, 직접 만져 보며 배움 | **한 화면 한 동작** | 장면 화면 = "누르기" 하나, 점검 화면 = "두 장 중 하나 고르기" 하나, 가요/멈춰요 = "밀기" 하나 | 일반 설계 관행 — 사실 근거 아님 |

- 세 건설 앱(Site Coach, Harness Hero, HazApp) 모두 **정식 교육을 대신하지 않는다**고 밝힌다 → 첫 삽도 같은 위치(법정 건설업 기초안전보건교육의 **보완**). 확인서에 "법정 교육 이수증이 아닙니다".
- 넣지 않은 것: 순위·돈·시간 압박·생명 잃기(레퍼런스 게임 일부의 시간·점수 경쟁 요소 포함).

## 2. 장치 → 화면 대응 (확인 9-8번용 표)

| 장치 | 출처 레퍼런스 | 첫 삽 화면 | 상태 |
|---|---|---|---|
| 장면 속 위험 찾기 | Site Coach, HazApp, SIF 포스터 | 장면 0~6 | 완료 |
| 무작위 출제 | Site Coach | 장면 다시 하기·오늘의 위험 찾기 | 2단계 |
| 찾기 → 어떻게 할까 | HazApp, KYT 3라운드 | 장면 끝 그림 3장 고르기 | 2단계 |
| 두 장 비교(지킨/안 지킨) | 서울시 그림책 | 찾은 위험 카드, 그림 점검 | 완료 |
| 가요 / 멈춰요 밀기 | (첫 삽 고안, 그림책 비교 방식 응용) | 구역별 5장, 출근 전 1분 | 2단계: 정문·보호구 1세트 |
| 입혀보기·걸 곳 고르기 | Harness Hero | 레슨 3 입혀보기(v11) / 고리 걸기 | 고리 걸기는 3단계 |
| 표지 색·모양 아이콘 | 공단 픽토그램, 안전보건표지 | 위험 종류 아이콘 11종 | 완료(직접 그림) |
| 지도 진행·연속일·캐릭터 | Duolingo | 현장 지도, 연속 n일, 삽이 | 완료 |
| 한 화면 한 동작 | Brilliant | 모든 장면·점검 화면 | 완료 |
| 듣기 버튼 | (접근성) | 모든 화면 상단 | 2단계 |

## 3. 확인하지 못한 것
- 공단 외국인 픽토그램 원본·활용 안내(OPS)·공공누리 유형 — 파일을 받으면 방식 대조
- 서울시 그림책 PDF — 방식 대조용(앱에 넣지 않음)
- 바탕 화면 `첫삽` 폴더의 「19. 무재해 사업장을 위한 위험 예지 훈련.mp4」 — 동영상은 내용을 직접 확인할 수 없어 참고하지 않음
