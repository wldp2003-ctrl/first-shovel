## 2. 번역 범위와 방식
- 범위: 교육 앱 화면 문구 342개 + 교육 내용 135개(위험 이름·안전 문장·상황 문장·행동·위험 종류·구역 이름·구역 상황) = 언어당 477문장. 기초 레슨 6개(글 과정)는 번역하지 않고, 다른 언어에서는 목록을 숨김
- **번역은 AI(Claude) 초안이며 원어민 검수 전이다.** 화면 설정과 언어 화면에 "AI가 번역한 초안(검수 전)"을 표시하고, 안전 문장 아래에는 **한국어 원문**을 함께 보여 준다(한국인 동료·반장과 함께 확인)
- 근거 칩(법령·기본서 이름과 원문 인용)은 한국어 원문 그대로 둔다
- 읽어 주기는 그 언어의 기기 음성. 기기에 그 언어 음성이 없으면 다른 언어로 읽지 않고 한 번 안내

## 3. 확인 방법
- `tools/i18n/export.mjs` → 원문 목록(`source.tsv`), `tools/i18n/build.mjs` → 번역 묶기 + 점검(변수 `{n}` 같음, 강조 `**` 수 같음, 빠짐 없음)
- `tools/_langshot.mjs <언어…>` → 타이틀·지도·미리 보기·찾기·카드·설정 화면에서 번역 안 된 한글 글자 수(한국어 원문 표시·근거 칩 제외)
- 결과(2026-11-26): 1차 8개 언어 모두 477/477, 화면 5종 남은 한글 0자, 오류 0

## 4. 한계
- 원어민 검수 0건 — 특히 안전 문장은 검수 전까지 한국어 원문과 함께 본다
- 기기 음성: 미얀마어·크메르어·우즈베크어 등은 많은 휴대폰에 기본 음성이 없음
- 한국계 중국인(83.7%)은 한국어를 읽는 분이 많아, 비율이 곧 번역 필요도는 아니다
