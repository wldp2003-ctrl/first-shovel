# 장면 검수표 (v19)

`docs/아트바이블.md`의 원칙에 v19 "한 장면 한 판단" 원칙을 더해 장면마다 점검합니다.
- **3초 테스트**: 상황 문장 없이 그림만 3초 보고 "무엇을 판단하라는 그림인지" 말할 수 있는가. 렌더링한 이미지(`assets/scenes/<구역>/<위험id>-bad|good.webp`)를 직접 열어 보고 판정했습니다.
  - 판정자는 오르카 1명입니다. 사용자·전문가 확인 전입니다.
- **주인공 화면 비율**: 판단할 사물이 화면 높이에서 차지하는 비율입니다. 눈으로 잰 대략값입니다.
- **상황 문장**: 그림을 설명하는 문장이고 답(무엇이 틀렸는지)은 말하지 않습니다. 굵은 말 = 그림 속 번호 표식(①②)입니다.
  - 표식은 두 모습(위험/안전)에 모두 있는 사물만 가리킵니다.
  - 근거는 같은 위험의 출처(src)이고, 상태는 `원문확인`입니다. 이 문장은 새 사실이 아니라 그림 설명이라서, 전문가 검토 때 함께 봐 주세요.
- **주목 영역(스포트라이트)**: 위험 자리(anchor) 둘레, 판단할 사물 크기만큼입니다. 틀린 부분 하나만 정확히 가리키지는 않습니다. 차이 부분은 "왜" 화면에서 처음 확대 원으로 보여 줍니다.
- 판정이 **보통**이면 3초 안에 알아볼 수 있지만 주인공이 50%보다 작은 장면입니다. 다음 손질 후보입니다.

## 이번에 다시 그린 장면
- **3-3 문이 열린 리프트**: 벽에 붙은 노란 상자였던 것을 랙앤피니언식 리프트로 새로 만들었습니다(v19.1). 3층 슬래브 위 눈높이에서 봅니다.
- **2-1 발판 사이 빈 곳**: 멀리서 내려다보던 구도를 같은 층 발판 위 근로자 눈높이로 바꿨습니다. 빈칸이 바로 앞에 뚫려 보입니다.
- **2-3 비계 아래로 지나가는 사람**: 가까이에서 근로자 눈높이로 보고, 앞을 가리던 라바콘·파이프·손수레를 치웠습니다.
- **3-1 매단 짐 아래 사람**: 리프트 방호선반이 짐을 가려서 구도를 옮겼습니다.
- **6-3 피복이 벗겨진 전선**: 안전한 모습에서 정리된 전선이 화면 밖이어서 구도를 올렸습니다.
- **새 위험 3-5(과적재)·3-6(하부 방호울)**: 리프트 장면에 더했습니다. 근거는 안전보건규칙 제135조·제20조 제6호 가목, 별표 3 제14·16호입니다.
