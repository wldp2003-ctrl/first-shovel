# 첫 삽 기초 교육 설계 (v11 · 1단계)

> 건설현장에 처음 온 사람이 꼭 알아야 할 기초를 **20~30분** 안에 빠르고 쉽게 익히고, 이해했는지 확인하는 앱.
> 2단계(나중): 기초를 마친 사람이 기존 3D 게임("현장 연습")으로 반복·심화.

작성 2026-11-16 · 레슨 데이터 `www/data/lessons.json` · 이 문서의 4~6장은 `node tools/gen-learn-doc.mjs`로 데이터에서 자동 생성

## 1. 원칙

| 항목 | 정한 것 |
|---|---|
| 대상 | 건설현장에 처음 왔거나 근속 6개월 미만인 근로자(일용직 포함), 한국어 우선 |
| 시간 | 레슨 하나 3~5분, 기초 전체 20~30분. 레슨 단위로 저장해 "이어서 하기" |
| 수준 | 건설 지식이 없어도 이해. 그림 1장 + 한 줄 (+ 한 줄 더) |
| 글자 수 | 카드 한 장(본문 + 보조 줄)의 글자 수, 공백 제외 40자 이내 |
| 위치 | 법정 교육을 **대신하지 않음**. 법정 교육에서 들은 것을 짧게 다시 확인하고, 현장을 미리 아는 도구 |
| 방향 | "가지 마세요"가 아니라 "현장은 이렇게 돌아가고, 이 작업은 이래서 위험해요" |
| 애매하면 | 뺀다. 기초에 없어도 되는 것은 2단계(게임)로 |
