# 그림만 모드 규칙 (v20 라운드 3, 2026-11-25)

- 대상: 한국어 글을 읽기 어려운 사람(외국인 근로자 등). 설정의 "보기 → 그림만"(처음 실행의 "보기 방식"에서도 고름). 기본은 "글과 그림"
- 배경: v14에서 지도교수 의견으로 그림 모드를 없앴고, v20에서 설정으로 되살림(확인 대기 — `docs/점검/애매한_구현.md` 15번). 라운드 1 점검에서 그림만 모드인데 화면에 한글이 157~597자 남아 있어(심사위원 ④) 이 규칙을 정함

## 1. 남기는 것
| 종류 | 예 | 이유 |
|---|---|---|
| 누르는 단추 | 아이콘(+필요하면 짧은 글) | 다음에 무엇을 누를지 그림으로 알 수 있어야 함 — 아이콘 없는 단추 0(자동 점검) |
| 그림 | 장면, 위험·안전 그림 쌍, 위험 종류 아이콘, 첫삽이 표정 | 내용의 중심 |
| 숫자·별·진행 | 찾은 수 3/6, 별, 진행 점, 시간 | 글 없이 읽힘 |
| 듣기 | 화면 위 듣기 단추(화면 전체 읽기), 문항·카드별 듣기, 그림만이면 화면이 열릴 때 자동으로 읽기 | 숨긴 문장을 귀로 |
| 짧은 이름표 | 위험 종류(맞음·떨어짐), 구역 이름(0 출근·TBM) | 4~6자, 아이콘 옆. 글을 읽는 동료가 함께 볼 때 도움 |
| **핵심 안전 문장** | 위험마다 1줄("매단 짐 아래로 다니지 않아요") | 교육의 결과물. 안전 카드(이미지로 저장·공유)에 들어가므로 남기고, 듣기로 읽음 |
| 법적 고지 | "법정 안전교육을 대신하지 않아요"(타이틀 아래) | 오해 방지 — 줄이지 않음 |

## 2. 숨기는 것 (듣기로 대신)
| 종류 | 화면 | 방법 |
|---|---|---|
| 설명·안내 문장 | 미리 보기 "여기서 하는 일" 칸(헤더에 구역 이름·위험 아이콘이 있음), "어디에 있는지는 직접 찾아요", 찾기 화면의 구역 설명, 어떻게 할까의 안내 문장("방금 찾은 위험", "알맞은 행동 그림을 골라 보세요" — 손가락+? 그림이 대신), 지도 부제, 빈 목록 안내 | 화면에서 숨김(`display:none`) |
| 근거 칩·출처 줄 | 미리 보기·결과·안전 카드 | 숨김 — 근거 확인은 글과 그림 모드에서 |
| 상황 문장 | 결과·안전 카드 | 숨김 — 그림 쌍이 대신 |
| 제목 문장 | 찾기 "조심할 것 N가지를 찾아 눌러 보세요", 미리 보기 "여기서 조심할 것 N가지", 결과 "현장 안전 카드가 생겼어요" | 눈에는 안 보이고 화면 읽기 프로그램에만(접근성 제목 유지) |
| 레슨(글 문제·요약) | 다시 보기 | 그림만이면 안 보임 — 레슨은 글 위주의 선택 과정 |

## 3. 예외 화면 (글이 남는 것이 맞음)
- **확인서**: 문서(이름·날짜·고지). **정보**: 만든 사람·출처·라이선스. **환경 설정**: 설정 이름(아이콘 있음). **설문**: 척도 문장은 그림으로 바꾸면 척도가 달라짐 — 듣기로. **소개(이 앱은?)**: 짧은 한 줄 + 그림. **내 기록**: 구역 이름·횟수·시간(숫자 위주)

## 4. 확인 방법
- `tools/audit-r1.mjs`: 그림만 모드 화면마다 본문 한글 글자 수와 글자 덩어리 목록(`blocks`), 아이콘 없는 단추 수
- 목표: 본 과정 화면(미리 보기·찾기·어떻게 할까·결과) **각 글자 덩어리가 핵심 안전 문장 또는 이름표뿐**, 아이콘 없는 단추 0
- smoke-v13 1번: 글자를 모두 가리고도 처음부터 확인서까지 감
