# 위험 장면 명료성 점검 (v16, 2026-11-22)

> v15 3D 장면 29곳(위험 29 + 안전한 곳 7)을 "무엇이 위험한지 한눈에 보이는가"로 다시 점검하고 고친 기록입니다.
> 계기: 사용자 피드백(11/22) — 굴착면(4-4)은 구덩이가 아니라 흙벽 두 개처럼 보이고, 맨홀(6-2)·폭염(6-4)은 무엇을 말하는지 불분명함.

## 2. 규칙 (29곳 모두 적용)

1. **에너지가 보인다**: 높이, 매단 짐, 움직이는 장비, 전선, 불티, 해
2. **노출된 사람이 보인다**: 아래에 있다, 사이에 있다, 끝에 서 있다
3. **위험한 모습과 안전한 모습은 같은 구도에 차이 하나**: 그 차이가 크게 보인다
4. **사고 장면이 아니다**: 쓰러진 사람 없이, 사고 "직전"의 흔한 모습
5. **누를 곳은 물체 위**: 위험한 모습 물체의 3D 경계 상자 중심으로 자동 계산(`anchor: null`). 빈 칸이나 높이처럼 물체가 없는 위험만 손으로 정함
6. **가까이 찍은 그림은 물체 크기에 맞춰 카메라 거리를 정한다**
7. **위험 목록·문장·출처는 바꾸지 않는다**: `scenes.json`, `sources.json` 그대로

## 3. 고친 것

| 위험 | 전(v15) | 후(v16) |
|---|---|---|
| 4-4 가파른 흙벽 | 땅 위에 흙벽 두 개, 동그라미가 빈 땅을 가리킴 | 땅에 **실제 구덩이**(깊이 2.4m). 위험한 모습: 수직 벽, 벽의 금, 가장자리 흙더미, 바닥에서 일하는 사람. 안전한 모습: 같은 구덩이를 비탈로. 위에서 내려다보는 구도 |
| 6-2 맨홀 | 검은 원 위에 앉은 사람 | 맨홀 테두리, 밖으로 나온 사다리, 옆에 벗긴 뚜껑, 사다리로 내려가는 사람. 안전한 모습: 삼각대, 송풍기와 호스를 맨홀 안으로, 밖에서 가스 측정기로 재는 사람 |
| 6-4 땡볕 | 누운 사람(쓰러진 사고처럼 보임) | 하늘에 해, 땡볕 아래 앉아 땀을 닦는 사람. 안전한 모습: 그늘막 아래 물병 |
| 3-1 매단 짐 아래 | 가까이 찍은 그림에 짐이 없음 | 아래에서 올려다보는 구도로 짐과 사람을 한 화면에. 안전한 모습: 짐 아래 원형 통제(콘) 밖으로 |
| 1-2 바닥 끝 | 빈 하늘만 보임 | 끝 가까이 서 있는 사람과 아래가 보이는 구도. 안전한 모습: 안전난간과 발끝막이판 |
| 1-3·2-2·2-4 안전대 | 가는 끈이라 차이가 안 보임 | 어깨·가슴·허리·다리 끈을 굵고 밝은 노랑(`--brand`)으로, 등 고리와 걸이 줄까지 |
| 2-1 발판 빈틈 | 아래에서 봐서 틈이 안 보임 | 위에서 내려다보는 구도, 틈 옆에 자재를 든 사람 |
| 1-4 길을 막은 자재 | 걸릴 사람이 없음 | 통로를 걸어오는 사람. 안전한 모습: 자재를 통로 옆에 쌓음 |
| 6-1 불티 옆 페인트통 | 통이 작고 가려짐 | 통 3개와 단열재 상자를 크게, 불티를 많이 |
| 6-3 벗겨진 전선 | 드러난 부분이 점처럼 작음 | 물웅덩이 위에 구리선이 벌어진 모습, 낮은 구도 |
| 5-4 펌프카 붐 | 안전한 모습에 붐이 안 보임 | 넓은 구도로 붐과 전선을 함께 |
| 2-3·4-2 안전한 모습 | 사람이 카메라 앞을 막음 | 통제선 밖, 옆 자리로 |
| 3-3 리프트 문 | 왜 위험한지 안 보임 | 열린 문 앞에 선 사람(떨어질 위치) |
| 0-1 안전모 | 너무 멀리서 찍음 | 머리 가까이 |
| 0-3 운동화 | 이유가 안 보임 | 발 옆에 철근 토막, 못이 박힌 각재 |
| 토공 장면 배치 | 롤러가 구덩이·굴착기와 겹침 | 롤러를 오른쪽 뒤로 옮기고 신호수 자리를 다시 고름(누를 곳 간격 60 이상) |
