# 에셋 라이선스 (v18)

앱에 들어가는 3D 모델, 질감, HDRI, 렌더링 이미지의 출처와 이용 조건입니다.
- 전체 목록은 `data/media.json`에 있습니다. `node tools/smoke-v13.mjs`의 7번 항목이 빠진 기록이 없는지 확인합니다.
- 통일 규칙은 `docs/아트바이블.md`, 치수 근거는 `docs/모델_치수.md`에 있습니다.

## v18 원칙: 0원
- **유료 API와 유료 에셋은 0개**입니다. 무료(CC0 우선, CC-BY 허용)이거나 직접 만든 것만 씁니다.
- 원본(zip, glb, 1k 질감, hdr)은 `art/src/`에 둡니다. **저장소와 배포에는 넣지 않습니다.**
- 앱에는 도구로 줄이고 다시 입힌 결과만 넣습니다.
  - `tools/import-cc0.mjs`: CC0 모델 → `assets/models/*.json`
  - `tools/prep-textures.mjs`: 질감·HDRI → `assets/tex/*`
  - `tools/blend-export.py`: `.blend` 원본 → GLB (무료 Blender 휴대용판을 도구로만 씀, `art/src/tools/`. Blender의 GPL은 만든 결과물에 적용되지 않음)
- 쓰지 않는 것:
  - 유료이거나 재배포가 제한된 마켓(CGTrader, TurboSquid, Fab 유료)
  - Hunyuan3D(한국 제외 라이선스)
  - 워터마크가 있거나 출처를 모르는 이미지
  - 참고 이미지(재능넷 상품)
  - 공공누리 4유형 그림
  - 검색한 사진

## 추가 규칙 (에셋을 넣을 때)
1. CC0 또는 CC-BY만 씁니다. 그 밖의 라이선스는 쓰지 않습니다.
2. 이 표에 한 줄을 적고, `data/media.json`에도 한 항목을 넣습니다.
3. CC-BY 에셋은 앱 안의 크레딧 화면(설정 아래 "만든 사람들")에 표기합니다. 이 화면은 첫 CC-BY 에셋이 들어올 때 만듭니다.
4. 모델은 `tools/import-cc0.mjs`의 목록에 넣어 재질 세트로 다시 입힙니다. 원래 텍스처는 쓰지 않습니다.
