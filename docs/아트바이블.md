# 첫 삽 아트 바이블 (v18 — 0원 "스타일라이즈드 실사" 3D)

출처가 다른 재료(코드 모델, CC0 모델, CC0 질감·HDRI)를 섞어도 **한 세트처럼** 보이게 하는 규칙입니다. 3D를 고치기 전에 이 문서를 먼저 봅니다.
- 관련 문서: `docs/에셋_라이선스.md`(출처), `docs/모델_치수.md`(치수 근거), `docs/art-direction.html`(v17 디오라마 구성)
- 비용: **0원.** 유료 API와 유료 에셋은 쓰지 않습니다.

## 1. 스타일
- **스타일라이즈드 실사**입니다. 비율과 재질은 실제처럼 하고, 디테일은 정돈합니다.
- 밝은 낮 장면입니다. 녹, 쓰레기, 피는 없습니다.
- 글자와 실존 회사 로고는 넣지 않습니다. 표지판은 색과 그림(안전모 모양 등)만 씁니다.
- 현장 인물은 실사 비율(키 약 1.72m)이고 **얼굴을 그리지 않습니다.** 그래서 얼굴과 국적이 드러나지 않습니다. 첫삽이 캐릭터(2D 마스코트)와는 구분합니다.

## 2. 통일 규칙 (가장 중요)
1. **같은 PBR 재질 세트로 다시 입힙니다** (`js/learn/materials.js`).
   - CC0 모델은 원래 텍스처를 버리고, 면마다 팔레트 색을 읽어 아래 재질 키로 바꿉니다(`tools/import-cc0.mjs`).
   - 재질 종류는 **12가지**입니다.

     | 재질 | 쓰는 곳 | 질감(Poly Haven CC0) | 거칠기·금속성 |
     |---|---|---|---|
     | concrete | 슬래브, 바닥 판, 방호벽 | concrete_floor_02 | 0.92 · 0 |
     | steel | 강관, 기둥, 철근 | metal_plate | 0.42 · 0.6 |
     | paint | 안전난간 노랑, 컨테이너 흰색, 표지판, 안전 4색 | 없음 | 0.5 · 0.05 |
     | plywood | 합판, 각재, 발판 | plywood | 0.78 · 0 |
     | dirt | 흙, 굴착 | brown_mud_dry | 1 · 0 |
     | gravel | 현장 바닥 | gravel_floor | 1 · 0 |
     | rubber | 바퀴, 밑창, 턱끈 | 없음 | 0.82 · 0 |
     | plastic | 라바콘, 장비 도장(주황) | 없음 | 0.36 · 0 |
     | vest | 형광 조끼 | 없음 | 0.62, 살짝 자체 발광 |
     | fabric | 작업복, 안전대 끈 | 없음 | 0.95 · 0 |
     | skin | 얼굴, 손 | 없음 | 0.72 · 0 |
     | glass | 창 | 없음 | 0.06 · 0.2 |

   - 같은 재질 종류에서는 **색만** 팔레트 토큰으로 바꿉니다(`paint:yellow`, `fabric:navy` 등).
2. **팔레트**: 색은 `css/tokens.css` 토큰에서만 가져옵니다.

   | 이름 | 토큰 | 색 |
   |---|---|---|
   | 흙 | `--pbr-dirt` | #8A6A4A |
   | 흙(밝은) | `--pbr-dirt-2` | #B08A5E |
   | 콘크리트 | `--pbr-concrete` | #A9ADB2 |
   | 강관 | `--pbr-steel` | #C7CCD1 |
   | 안전 노랑 | `--pbr-yellow` | #F2C230 |
   | 첫삽 주황 | `--pbr-orange` | #FF7A1A |
   | 남색 | `--pbr-navy` | #1F2A44 |
   | 바탕 | `--pbr-paper` | #F4F1EA |

   - 질감 사진의 색은 버리고 **흑백 결**(평균 밝기 0.9)만 씁니다. 그래서 어느 출처든 같은 색이 됩니다.
3. **같은 빛, 같은 그림자, 같은 톤매핑**
   - 렌더러 설정: `outputColorSpace = SRGB`, `toneMapping = ACESFilmic`, 노출 1.0입니다.
   - 환경광: 맑은 낮 HDRI(Poly Haven `kloofendal_43d_clear_puresky`)를 256×128로 줄여 PMREM으로 씁니다. 환경광으로만 쓰고 배경으로는 쓰지 않습니다.
   - 방향광은 1개입니다. 오전 햇빛이고 왼쪽 위에서 비추며, 따뜻한 색(바탕색 + 주황 14~16%)입니다.
   - 그림자: PCFSoft입니다. 그림자 카메라를 지도·장면 크기에 맞추고 bias를 조정했습니다.
   - 반구광은 0.45~0.5로 약하게 둡니다. HDRI를 읽지 못하면 v17처럼 1.25로 올립니다.
4. **모서리 베벨**: 3m 이하 상자는 모두 둥근 모서리 상자(`RoundedBoxGeometry`)로 만듭니다. 큰 판은 그대로 둡니다.

## 3. 질감 붙이는 법
- **월드 좌표 UV**(상자 투영)를 씁니다. 1m마다 같은 밀도라서, 인스턴싱으로 늘린 상자도 질감이 늘어나 보이지 않습니다.
- 해상도: 색 512, 노멀 512, 거칠기 256입니다(작은 금속은 256). 모두 WebP이고, 질감 15장 + HDRI를 합쳐 약 740KB입니다.

## 4. AO(맞닿은 곳의 어둠)
- **실시간 지도**: 지도를 만들 때 **접지 AO 텍스처를 한 번 굽습니다**. 땅에 닿은 물체의 바닥 자리를 부드럽게 어둡게 하는 1024px 캔버스입니다. 큰 물체에는 둥근 접지 그림자(v17)도 함께 씁니다. 실시간 SSAO는 쓰지 않습니다(휴대전화 성능 때문).
- **미리 렌더링 장면**은 고품질 설정으로 뽑습니다.
  - 그림자 4096, MSAA 4×, **SAO**(화면 공간 AO), 아주 약한 피사계 심도(BokehPass)를 씁니다.
  - 렌더링에는 실제 GPU(D3D11)를 씁니다.
  - GTAO는 바닥 판 하나에서 노멀이 비는 문제가 있어서 SAO로 바꿨습니다.

## 5. 안전 4색은 의미대로만
- 빨강은 금지·위험, 노랑은 주의, 파랑은 지시(꼭 할 것), 초록은 안전입니다.
- 안전 노랑(`--pbr-yellow`)은 안전모, 안전난간, 장비 도장에도 쓰지만 **표지 색**으로는 "주의"에만 씁니다.

## 6. 모델 만드는 법 (재료 4가지)
| 재료 | 무엇에 | 지금 (v18) |
|---|---|---|
| ① 코드로 정확하게 | 안전 구조물, 보호구 | 근로자(`models/worker.js`: 안전모·턱끈·조끼·안전화·안전대·죔줄 부품 교체), 안전 구조물(`models/safety.js`: 안전난간·개구부 덮개·시스템 비계·이동식 비계·파이프 서포트 동바리), 표지판, TBM 게시판, 펜스, 컨테이너 창·문 |
| ② CC0 3D 모델 | 장비, 차량, 복잡한 소품 | 컨테이너 몸체, 라바콘, 콘크리트 방호벽, 경고등(Kenney) · 굴착기(Iacox) · 레미콘, 타워크레인, 덤프트럭(Majadroid) |
| ③ CC0 질감·HDRI | 실사 느낌 | 콘크리트, 흙, 자갈, 합판, 금속, 맑은 낮 하늘(Poly Haven) |
| ④ 무료 AI 3D (선택) | ①②로 안 되는 소품 | **쓰지 않음** |

- 위험한 모습과 안전한 모습은 **옵션 하나만 바꿔** 만듭니다. 예: `chinStrap:false`, `boots:false`, `cover:false`, `locked:false`, `bent:true`. 이것이 `scenes.json`의 bad/good과 1:1로 대응합니다.

## 7. 검수 기준 (렌더링을 다시 할 때마다)
1. 위험한 모습과 안전한 모습이 같은 카메라이고, 차이가 **하나**인가(`art/review` 비교 그림).
2. 누를 곳(area)이 그 물체 위에 있는가(3D 위치에서 자동 계산).
3. 글자, 로고, 얼굴이 없는가.
4. 재질 종류가 12가지 이하인가(`node tools/_kinds.mjs`, 장면마다 9~11가지). 6구역의 해는 빛을 받지 않는 기본 재질(MeshBasic)로 일부러 둡니다.
5. 용량: 3D 전체 8MB 이하.
