### 0-5. 모양
- 간격 4의 배수, 화면 좌우 16 · 모서리 12(작은 요소)/16(카드·버튼)/24(큰 패널)/원(길 위 구역)
- **두툼한 버튼**(`.t-btn`): 높이 52, 아래 4px 진한 테두리, 누르면 4px 내려가며 테두리 0 (0.08초). 보조 버튼은 흰 바탕 + 2px 테두리 + 아래 4px
- 선택지 카드: 흰 바탕 + 2px 테두리 + 아래 4px. **고르면 주황**(정답·오답 색과 구분), 확인 뒤 초록/빨강
- 아이콘: 직접 그린 SVG 24 격자, 선 2.5, 둥근 끝. 이모지 금지
- 피드백 바: 아래에서 올라옴. 정답 = 연한 초록 + 기쁨 얼굴 + "계속"(진한 초록), 오답 = 연한 빨강 + 걱정 얼굴(고개 기울이기) + 이유 그림 두 장 + "알겠어요"(진한 빨강). 제목 글자는 남색, 색은 아이콘(✓ 동그라미 / ✕ 네모)으로

### 0-6. 캐릭터 "첫삽이"
- 현장에 막 온 새내기 근로자 — 선생님이 아니라 **함께 배우는 동료**. 이름은 `locales/ko.json` 키로(바꾸기 쉽게)
- 국적·나이·성별이 드러나지 않게: 피부 한 톤, 머리카락은 안전모에 가림
- 얼굴: 아래가 살짝 넓은 둥근 사각형(1 : 0.92). 바깥 윤곽 **6px**(200×240 기준), 안쪽 선 4px, 모두 둥근 끝. 눈 = 세로 타원 + 반사점, 볼 = 주황 40%, 코·귀 없음
- 안전모: 주황, 앞 챙 + 가운데 홈 + 흰 삽 마크(로고와 같은 `shovelShape`). **턱끈**(교육 내용과 맞춤)
- 몸: 2.3등신, 주황 조끼 + 흰 반사띠 2줄, 장갑 낀 손, 안전화, 작은 삽
- 표정 7(기본·기쁨·놀람·걱정·생각·단호·자랑) × 자세 5(서기·인사·엄지척·손바닥·삽 들고 뿌듯) — `renderMascot({ pose, face, size })`
- 48px 이하는 볼·반사띠·장갑 홈선을 뺀 단순 버전 자동
- 움직임: 눈 깜빡임 5초마다, 정답 = 8px 통통, 오답 = 고개 기울이기(흔들기 없음). 동작 줄이기 설정이면 정지
- 파일: `assets/character/body-*.svg`, `face-*.svg` — `node tools/make-mascot.mjs`로 원본에서 만든다

### 1-2. 안전 표지 색 — **이 의미로만 쓴다**
산업안전보건법 시행규칙의 안전보건표지는 금지(빨강)·경고(노랑)·지시(파랑)·안내(초록)로 나뉜다. 외국인 근로자도 현장 표지에서 이미 이 색의 뜻을 익히므로 앱도 같은 규칙을 따른다.

| 색 | 값 | 뜻 | 앱에서 쓰는 곳 | 쓰지 않는 곳 |
|---|---|---|---|---|
| 빨강 `--red` | `#c62828` | 금지·위험·멈춤 | 오답 표시의 아주 작은 점, "멈추고 알려요" 레슨 배지, 기록 지우기 | 일반 버튼, 장식, 근거 등급 |
| 노랑 `--yellow` | `#f2b705` | 주의 | 사고 유형 레슨 배지, 초안 표시(개발 모드), 확인 필요 | 글자색(대비 부족), 진도 |
| 파랑 `--blue` | `#1d5fbf` | 지시(꼭 할 것) | 보호구 레슨 배지, "꼭 해요" 표시 | 주요 버튼(→ 남색), 링크 장식 |
| 초록 `--green` | `#12805c` | 안전·정답·안내 | 정답 체크, 완료 표시, 대피 안내 레슨 배지, 준공 깃발 | 일반 강조 |

- 주요 버튼은 **남색**이다 (파랑은 "지시"에만 남겨 둔다)
- 레슨 배지 색은 그 레슨 내용의 표지 종류를 따른다: 1·2 현장 입문 = 남색(중립), 3 보호구 = 파랑(지시 표지), 4 사고 = 노랑(경고 표지), 5 불·대피 = 초록(안내·피난 표지), 6 멈추고 알리기 = 빨강(정지)
- **그림(일러스트)** 안의 안전모·조끼 같은 실제 물건은 실제 색을 쓴다. 다만 화면 바탕·버튼·글자 강조에는 위 네 색을 의미 밖으로 쓰지 않는다
- 색만으로 뜻을 전하지 않는다: 정답은 체크 모양, 오답은 되돌아가기 모양을 함께 쓴다 (색약·외국인)

## 3. 아이콘
- 이모지는 쓰지 않는다 (기기마다 모양이 다르고, 뜻이 문화마다 다름)

## 5. 글이 길어져도 안 깨지게 (다국어 준비)
- 버튼·카드는 높이를 고정하지 않는다 (`min-height`만). 글이 길면 줄바꿈되고 칸이 늘어난다
- 그림 안에 글자를 넣지 않는다 → 그림은 언어와 무관. (v11 그림 일부에 남은 글자 이름표는 그림 밖 캡션으로 옮기는 중)
- 화면 문구는 `locales/ko.json`의 `learn.*` 키로 둔다. 번역은 아직 하지 않는다. 레슨 문장은 `data/lessons.json` 그대로 (근거 검증 대상)
- 시험: `?pseudo=1`을 붙이면 모든 화면 문구가 40% 길어진 가짜 문장으로 바뀐다

## 9. 그림 모드 규칙 (v13 — 글을 못 읽는 사람도 끝까지)
> 교수님 피드백(글 못 읽는 외국인 근로자)과 레퍼런스(서울시 무번역 그림책, 공단 외국인 픽토그램, Brilliant의 한 화면 한 동작) — [`레퍼런스.md`](레퍼런스.md)

| 규칙 | 어떻게 |
|---|---|
| 모드 고르기 | 처음 안내 끝에 그림 버튼 2개: **눈+손가락 = 그림으로**(기본) / **줄 글 = 글도 함께**. 위쪽 버튼으로 언제든 바꿈 |
| 한 화면 한 동작 | 장면 = 누르기, 점검 = 두 장 중 고르기, 어떻게 할까 = 세 장 중 고르기, 가요/멈춰요 = 밀기 |
| 안내 | 글 대신 **손가락 아이콘**과 손가락이 눌러 보이는 움직임. 답의 위치는 알려 주지 않는다 |
| 누를 곳 | 모두 그림이나 아이콘이 있어야 함(글만 있는 버튼 금지), 48px 이상. 장면 위 누를 영역 지름 54px |
| 정답 / 오답 | **초록 동그라미 + 체크** / **빨간 네모 + X** — 색과 모양 둘 다(색약), 정답에 짧은 진동. 벌점·생명 잃기 없음, 틀리면 바른 답을 보여 주고 넘어감 |
| 위험 설명 | "위험한 모습(빨간 테두리 ✕) → 안전한 모습(초록 테두리 ✓)" 두 장 그림 |
| 위험 종류 | 경고 표지(노랑 삼각형) 안에 직접 그린 그림 11종: 떨어짐·넘어짐·찔림·맞음·부딪힘·끼임·무너짐·감전·불·질식·더위 |
| 행동 | 멈춰요 = 빨간 원 안의 손바닥(금지 표지 모양) / 알려요 = 느낌표 말풍선 + 관리감독자(흰 안전모) / 보호구 = 파란 원 체크(지시 표지 모양) |
| 가요 / 멈춰요 | 왼쪽 = 빨강 ✋ 멈춰요(둥근 버튼), 오른쪽 = 초록 ✓ 가요(네모 버튼). 밀기와 버튼 둘 다 |
| 듣기 | **모든 화면** 위쪽 오른쪽 스피커 버튼: 그 화면에서 할 일을 기기 음성(한국어)으로 읽음. 소리가 없어도 이해되게 그림이 먼저 |
| 숫자 | 장면 번호·별·점수 점(●)은 그림 모드에서도 보임(숫자는 대부분 읽을 수 있음) |
| 삽이 | 그림 모드에서는 말풍선 없이 **표정만**(웃음 = 잘함, 생각 = 다시 보자) |
| 글이 남는 곳 | 모드를 고르기 전 안내·언어 화면, 법정 교육 안내 문구, 확인서 — 진행에는 필요 없음 |
