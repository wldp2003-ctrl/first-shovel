# 첫 삽 사업계획서 (프로젝트 개요)

## 1. 과제 개요

| 항목 | 내용 |
|---|---|
| 과제명 | 첫 삽: 작업 이해 기반 위험 인지를 위한 건설 신규 근로자 게임형 입문 교육 |
| 수행자 | 전남대학교 건축학부 건축공학전공 4학년 곽지예 |
| 성격 | 캡스톤 디자인 결과물 + 학술 논문 주제 |
| 기간 | 캡스톤: 2026년 11월 ~ **12월 7일(월) 마무리** · 논문: 12월 7일 이후 (마감 미정) |
| 결과물 | 캡스톤: 휴대전화 설치형 교육 앱 1종(한국어), 예비 검증 결과, 발표 자료 · 논문: 현장 검증 결과와 원고 |

## 2. 추진 배경 및 필요성

1. **사고는 처음 온 사람에게 몰린다.** 2025년 건설업 사고 사망자의 82.3%가 근속 6개월 미만이다.
2. **건설업이 사망 사고의 절반 가까이를 차지한다.** 2025년 사고 사망자 605명 중 286명이 건설업이다.
3. **첫 교육은 4시간 한 번이다.** 이후 재교육 의무가 없고, 현장에서는 이수증 확인마저 형식적으로 이뤄진다는 보도가 있다.
4. **근로자는 위험의 절반가량을 알아보지 못한다.** 해외 연구에서 근로자의 위험 인지율은 주요 위험 유형에서 약 47%였다.
5. **정책은 근로자의 판단을 요구한다.** 2025년 노동안전 종합대책은 작업중지권 요건을 완화하고 위험성평가에 근로자 참여를 의무화했다. 위험을 알아볼 수 있어야 이 권리를 쓸 수 있다.

## 3. 목적 및 목표

**목적:** 신규·초보 근로자가 작업의 순서와 기준을 직접 해보며 익히고, 그 작업의 위험을 스스로 알아보고, 위험할 때 멈추고 알릴 수 있게 한다.

| 목표 | 측정 방법 | 목표치 (안) |
|---|---|---|
| 위험 인지 향상 | 사진 속 위험 찾기 사전·사후 | 사후 인지율이 사전보다 유의하게 높음 |
| 이해도 향상 | 같은 문항 사전·사후 | 정답률 상승 |
| 꾸준한 사용 | 7일 사용 기록 | 하루 5분 이상 사용자 비율 |
| 현장 수용성 | 반장·안전관리자 인터뷰 | TBM 보조 자료로 쓸 의향 |

> 목표치 숫자는 예비 시험 후 확정한다.

## 4. 주요 내용

| 구성 | 내용 |
|---|---|

| 매일 현장 | 작업 버튼으로 건물을 쌓으며 공정 순서와 날씨에 따른 작업 판단을 익힘 |
| 무전 이벤트 | 동바리 처짐, 개구부 덮개 빠짐, 용접 불티, 밀폐공간 등 실제 사고 유형 상황 판단 |
| 미니게임 | 레미콘 검사, 창문 닦기(안전대), 유리 운반(2인 1조), 휴식 장소, 폭염 대비, 현장 용어 |
| 야간 당직 | 문단속, 전기, 불씨, 자재 결속 점검 |
| 근거 표시 | 모든 결과 카드에 근거(법정·표준·게임 단순화) 표시 |
| 기록 | 배움 노트, 사전·사후 테스트, 오답 기록 |

## 9. 기대 효과

- **근로자:** 첫 출근 전에 작업과 위험을 미리 익혀 입직 초기 사고 위험을 줄인다
- **현장:** TBM 보조 자료로 같은 내용을 반복 확인할 수 있다
- **학술:** 신규 근로자 대상 게임형 교육의 위험 인지 효과를 실제 현장 자료로 검증한다
- **정책:** 작업중지권·위험성평가 참여가 실제로 작동하는 데 필요한 "위험을 알아보는 능력"을 키운다

## 10. 위험 요소와 대응

| 위험 | 대응 |
|---|---|
| 게임 내용이 실제 기준과 다름 | 근거 3단 표시, 전문가 검토, 조문 원문 확인 |
| 근로자가 앱을 쓰지 않음 | 하루 5~10분, 설치 없이 바로 실행, TBM과 연계 |
| 캡스톤 기간이 짧음 (3주) | 캡스톤은 예비 시험까지만, 실제 현장 시험은 논문 단계로 나눔 |
| 협조 현장 섭외 실패 | 교내 실습 현장·직업훈련기관 신규 교육생으로 대체 |
| 연구윤리 문제 | 시험 전 IRB 필요 여부 확인, 개인정보 수집 최소화 |
| 외국인 근로자 미포함 | 한국어 검증 후 다국어 확장 단계로 명시 |
