# 첫 삽 기초 교육 — 전문가 검토지

**검토자:** ______________ (소속·직위: ______________ · 현장 경력 ____년) **검토일:** ____. ____. ____.

현장 안전관리자·교수 3~5명이 각자 따로 작성합니다. 문장마다 세 기준에 1~4점을 적어 주세요.

| 점수 | 뜻 |
|---|---|
| 4 | 매우 그렇다 (그대로 사용) |
| 3 | 그렇다 (조금 다듬으면 사용) |
| 2 | 그렇지 않다 (많이 고쳐야 함) |
| 1 | 전혀 그렇지 않다 (빼야 함) |

- **정확성:** 법령·기준·현장 사실과 맞는가
- **이해 쉬움:** 건설현장이 처음인 사람이 바로 이해할 수 있는가
- **현장 적합성:** 실제 현장에서 쓰는 말·상황에 맞고 도움이 되는가
- 근거 원문은 `docs/근거대조표.md`의 같은 번호를 보세요.

## 내용타당도지수(CVI) 계산 방법
- 문항별 I-CVI = (3점 또는 4점을 준 검토자 수) ÷ (전체 검토자 수). 기준별로 따로 계산
- 검토자 3~5명이면 I-CVI 1.00을 권장 기준으로 삼는 문헌이 있음 (Lynn, 1986, Nursing Research 35(6) — 4등급, 본문 확인 필요, 설계 근거용)
- 전체 S-CVI/Ave = 문항 I-CVI의 평균. 0.90 이상이면 양호로 보는 문헌이 있음 (Polit & Beck, 2006 — 4등급, 본문 확인 필요)
- I-CVI가 낮은 문장은 의견을 반영해 고친 뒤 status를 `전문가확인`으로 바꿉니다
