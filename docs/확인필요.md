# 원문 확인 필요 목록

1~3등급 원문으로 아직 확인하지 못한 것. 확인할 때까지 **앱 화면에 쓰지 않는다** (게임 근거 카드는 "확인 중" 표시).
확인하면 이 표에서 "해결"로 옮기고 `data/sources.json`에 출처를 올린다. 갱신 2026-11-16.
