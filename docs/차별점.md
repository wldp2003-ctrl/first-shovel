# 첫 삽의 차별점 (v17)

"건설 지식을 넣고 버튼을 누르면 나오는 앱"과 다른 점은 기능 개수가 아닙니다. 차별점은 **검증, 현장성, 효과 증거** 세 가지이고, 이 셋이 **모든 화면에서 보이게** 합니다.

| 차별점 | 화면에 보이는 방식 | 들어간 화면 (v17) |
|---|---|---|
| 검증된 내용 | 모든 위험 문장과 정리 카드 줄에 **근거 배지**(법령·공단 기본서·KCS, 조·쪽까지). 배지를 누르면 원문 인용이 나옴. 화면에는 `원문확인` 이상만 나옴. **"전문가 검토 완료"** 표시 자리는 그 구역의 모든 문장이 `전문가확인`이 되면 켜짐 | 안전 카드 줄마다 근거 배지(`.basis-chip`), 카드 아래 근거 목록, 미리 보기 "이 장면의 근거", 찾음 피드백 아래 근거 |
| 실제 사고에서 온 장면 | 장면마다 "이 장면은 ○○·○○ 사고 유형에서 만들었어요"와 공단 기본서 쪽. 재해 유형은 `scenes.json`의 `type`(공단 재해 유형 이름)에서 나옴. 개인정보와 실제 사고 사례 내용은 넣지 않음 | 미리 보기 카드 아래 "사고 유형에서 만든 장면" 줄 |
| 현장에서 쓰는 순서 | 지도 = **출근해서 현장을 한 바퀴 도는 동선**(출근·TBM → 골조 바닥 → 비계 → 양중 → 장비 → 타설 → 용접·밀폐). 땅 위 주황 점선이 동선. 정리 카드 = **TBM에서 반장에게 보여 줄 한 장**(이미지 저장) | 첫 화면 지도 위 "현장 한 바퀴" 줄과 `n/7 구역`, 주황 점선 동선, 안전 카드 "이미지로 저장" |
| 효과를 재는 앱 | 사전·사후 그림 점검(그대로). 구역마다 **처음 찾은 수 → 다시 찾은 수** 변화. 힌트를 쓴 횟수도 기록 | 내 기록 "구역별 변화" 표, 내보내기 자료(`first`·`hints`) |
| 글을 못 읽어도 | 지시마다 듣기 버튼. 미리 보기는 위험 종류 **아이콘**으로, 카드는 번호·그림·✕/○ 모양으로 읽힘. 글자는 늘 그림과 함께(v14 결정: 글만 숨기는 모드는 없음) | 미리 보기 아이콘, 찾기 빈칸 아이콘, 카드 번호 핀·✕/○, 듣기 |

## 원칙
- 차별점을 말로 자랑하지 않고 **화면 요소로** 보입니다. 배지, 동선, 카드, 변화 숫자가 그 요소입니다.
- 근거 배지와 사고 유형 줄은 이미 검증한 데이터(`sources.json`, `scenes.json`)에서 자동으로 만듭니다. 새 사실 문장은 만들지 않습니다.
- 전문가 검토 표시는 실제로 검토했을 때만 켭니다(`status: 전문가확인`). 지금은 꺼져 있습니다.
