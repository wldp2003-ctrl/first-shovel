# 현장 말 미리 보기 (v22)

## 왜
건설을 배운 적 없는 사람(처음 온 사람·외국인)은 "동바리·비계·개구부·적재하중" 같은 이름만 보고는 그것이 무엇인지 모른다. 그런데 앱의 상황 문장과 안전 문장은 이 말들을 그대로 쓴다. 사전처럼 뜻을 풀어 주는 것보다, **실제 모습을 먼저 보고 알아보게** 하는 편이 현장에서 바로 찾는 데 도움이 된다.

## 무엇을 했나
| 곳 | 하는 일 | 시간 |
|---|---|---|
| 구역에 **처음** 들어갈 때 | 첫삽이(진행자)가 "현장에서 자주 듣는 말 N개를 사진으로 먼저 볼게요" → 실제 사진 카드 2~4장(한국어 이름 크게 + 번역 + 생김새 한 줄 + 함께 알아 둘 말) → **골라 보기 1문제**(방금 본 사진 중 "○○는 어느 사진?") → 바로 미리 보기 | 약 20~30초 (자동 점검에서 카드 4장+문제 약 5초에 넘김) |
| 건너뛰기 | "다 알아요, 건너뛰기" — 아는 사람은 바로 넘어감. 기록에 건너뜀으로 남음 | 0초 |
| 미리 보기 | "여기서 듣는 말 — 누르면 사진" 칩 줄 | 필요할 때 |
| 상황 문장 | 굵은 말이 현장 말이면 점선 밑줄 + 눈 아이콘 → 누르면 사진 | 필요할 때 |
| 다시 보기 탭 | "현장 말 사진" 24개 전체 | 필요할 때 |
| 결과 파일 | `terms`: 구역별 본 시간(초)·골라 보기 맞음/틀림·건너뜀 | — |

- 외국인: 현장에서는 한국어로 듣기 때문에 **한국어 이름을 크게**, 그 아래 고른 언어 번역. 20개 언어 모두 번역(AI 초안, 검수 전)
- 그림만 모드: 사진 + 한국어 이름(+번역) + 듣기만, 설명 글은 숨김(그림만 모드 규칙)
- 구역 순서대로 3~4개씩 나눠 보여 줌 — 한꺼번에 24개를 외우게 하지 않음(인지 부하)

## 참고한 교육용 앱의 방식
- **듀오링고**: 새 단어를 그림·소리와 함께 먼저 보여 주고 곧바로 고르게 하는 흐름, 문장 속 단어를 누르면 뜻이 뜨는 힌트 → "사진 카드 → 골라 보기 1문제", "굵은 말 누르면 사진"
- **게임 튜토리얼의 진행자(NPC)**: 캐릭터가 말풍선으로 짧게 안내하고 넘기기 → 첫삽이 말풍선, 옆으로 밀어 넘기기
- 처음 한 번만 자동으로, 그 뒤에는 필요할 때만(칩·밑줄·다시 보기) — 본게임까지 오래 걸리지 않게

## 사진 원칙 (저작권)
- **위키미디어 공용(Wikimedia Commons)의 자유 라이선스 사진만**: CC0·퍼블릭 도메인(미국 정부 기관 사진 포함)·CC BY·CC BY-SA. 검색 결과에서 라이선스를 자동으로 걸러 받음(`tools/terms/find.mjs`), 사진마다 작성자·라이선스·원본 주소를 기록(`tools/terms/credits.json`)
- 화면: 사진 아래 "사진 · 작성자 · 라이선스 · Wikimedia Commons", 앱 정보 화면에 전체 목록(링크 포함) — CC BY·BY-SA 표시 의무
- 가공: 4:3으로 가운데 자르고 800×600 WebP로 줄임(`tools/terms/pick.mjs`). CC BY-SA 사진의 이 가공본도 같은 CC BY-SA
- 맞는 자유 라이선스 사진을 못 찾은 2개(개구부·이동식 비계)는 v22.2에서 **국내 현장 모습을 보고 3D로 새로 그렸다**: 개구부 = 뚫린 구멍 + 주황색 철망 덮개(각관 테두리·망·표지판), 이동식 비계 = 아시바 틀비계(폭 0.9m 끝틀·1.83m 교차가새·단 1.7m·노란 발판·바퀴 스토퍼·고임목). 검색에서 본 블로그·업체·쇼핑몰 사진은 라이선스를 확인할 수 없어 모양 참고로만 쓰고 앱에 넣지 않음. 화면 표시: "그림: 첫 삽 3D (국내 현장 모습을 보고 그림)". 같은 모델을 교육 장면 1-1·2-5·x-1 에도 반영
- 구글 이미지 검색 결과는 라이선스를 확인할 수 없어 쓰지 않음. 공공기관(안전보건공단 등) 자료는 공공누리 유형 확인이 필요해 이번에는 쓰지 않음(후속)

## 설명 문장
- 생김새·어디서 보는지 설명이고 안전 규칙이 아니다(안전 규칙은 근거 있는 `scenes.json` 문장이 맡음). 상태: 초안 → 전문가 검토지(`docs/전문가검토지_장면.html` "현장 말 사진")에서 "사진이 맞음·설명 정확성·이해 쉬움"을 받는다
- 원본: `tools/terms/terms.src.json` → `node tools/terms/build.mjs` → `data/terms.json`

## 사진 바꾸는 법
1. `node tools/terms/find.mjs <임시폴더> <id> "검색어"` → `python tools/terms/sheet.py <임시폴더>/<id>` 로 후보 모아 보기
2. `node tools/terms/pick.mjs <임시폴더> <id> <후보폴더> <번호> [cx,cy]`
3. `node tools/terms/build.mjs` → 확인 `node tools/_terms.mjs [언어] [text|pic]`
