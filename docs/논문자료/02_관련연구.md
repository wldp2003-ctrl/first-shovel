# 02. 관련 연구와 기존 앱 검토

> 원자료: `docs/차별점_분석.md`(검색일 2026-11-24), `docs/차별점_분석_앱검색.csv`. 판정자가 1명이고 앱을 설치하지 않고 스토어 설명으로 판정했다는 한계가 있다(2.4절).

## 2.1 법정 기초교육의 구조
**표 2-1. 건설업 기초안전보건교육 관련 규정**

| 구분 | 내용 | 근거 |
|---|---|---|
| 대상·시간 | 건설 일용근로자 건설업 기초안전보건교육 4시간 이상 | 산업안전보건법 시행규칙 [별표 4] 제1호 마목 |
| 내용 | 공사 종류·시공 절차(1시간), 재해 유형별 위험요인·조치(2시간), 안전보건관리체제·권리·의무(1시간) | 같은 규칙 [별표 5] 제2호 |
| 방법 | 1시간 이상을 보호구 착용·화재·폭발 예방·피난에 관해 시청각 또는 체험·가상실습 | 안전보건교육규정(고시 제2025-77호) 제13조의2 제1항 제1호 |
| 근로자 권리 | 급박한 위험 시 작업 중지·대피 | 산업안전보건법 제52조 제1항 |

본 연구의 앱은 이 법정 교육을 **대신하지 않으며**, 교육에서 들은 내용을 현장 장면으로 다시 확인하고 출근 전에 반복하는 보조 도구로 위치시킨다.

## 2.2 선행연구
**표 2-2. 건설 안전교육 매체 관련 선행연구**

| 저자(연도) | 대상 | 매체 | 평가 | 주요 결과 | 한계 |
|---|---|---|---|---|---|
| 이종현 외(2023) | 앱 사용자·전문가 43명 | 모바일 앱 KNOWRISK(영상·퀴즈·신고) | MARS | 평균 4.074 | 현장 근로자 표본이 적음, 효과는 후속 연구 |
| 박현수·구충완(2022) | 건설 근로자 68명 | 사진 VR 시청 vs CG VR 체험 | 설문, t-검정 | 체험형이 통합 점수에서 높음, 지식 전이 항목 차이 없음(p=.411) | 콘텐츠·기자재 부족 |
| 조춘환(2023) | 체험 시설 이수자 | 실물·가상 체험 | 설문, 구조방정식 | 체험 교육과 의도된 안전 행동 관련 | 행동 직접 관찰 아님 |
| 노영희 외(2024a) | 외국인 건설근로자 VR 콘텐츠 | 공단 VR 콘텐츠 | 콘텐츠 분석 | 다양한 콘텐츠·찾아가는 교육 필요 | 효과 측정 없음 |
| 노영희 외(2024b) | 외국인 건설근로자 | 제도·통계 | 자료 조사 | 언어·문화 지원 필요, 관리자 중심 체계 | 실태 자료 중심 |
| 정경환 외(2015) | 외국인 건설근로자 | 이러닝 시제품 | 구현 | 외국인용 안전교육 모델 제안 | 한국어로만 구현 |
| Taha 외(2025) | 실무자 30명 | 360° 사진 위험 찾기 게임 | 사용성 설문 | UI 긍정 92% | 위험 인지 변화 측정 없음 |

해외의 고충실도 가상환경 위험 인지 연구(Albert 외, 2014)와 개인 맞춤 위험 인지 훈련(Jeelani 외, 2017)은 위험 인지가 훈련으로 나아질 수 있음을 보였으나, 원문을 확인하지 못해 수치는 인용하지 않는다.

## 2.3 기존 앱 체계적 검토
App Store·Google Play에서 한국·미국 대상 한국어 7개, 영어 5개 검색어로 각 17회 검색했다. 두 스토어 합계 1,269개 중 키워드 1차 선별로 191개, 설명을 읽는 2차 판정으로 30개(확실 19, 경계 11)를 포함했다. 두 스토어의 같은 앱을 합치면 27개다. 이름 검색과 논문으로 Harness Hero, KNOWRISK, 서울시 무번역 그림책, HazApp(2025 삭제)을 더했다.

## 2.4 공백과 본 연구의 위치
**표 2-4. 선행연구·기존 앱의 공백**

| 공백 | 근거 | 본 연구의 대응 | 남은 한계 |
|---|---|---|---|
| 효과 검증이 만족도 설문 중심 | 표 2-2 | 앱 안 사전·사후 그림 점검·구역별 인지율·SUS | 자료 아직 없음(7장) |
| 체험형 효과는 장비 의존 | 박현수·구충완(2022) | 휴대전화 3D 장면·미리 렌더링 그림 | 체험 강도는 VR보다 약할 수 있음(가설) |
| 교육 내용 근거 절차가 드러나지 않음 | 표 2-2의 연구에서 내용 검증 절차 기술을 찾지 못함(검토 범위 안) | 출처 등급·상태·원문 자동 대조(6장) | 전문가 확인 0 |
| 글을 읽기 어려운 근로자용 도구 검증 부족 | 노영희 외(2024a·b), 정경환 외(2015) | 그림만 모드 규칙(3장 DP5) | 외국인 시험 0, 한국어 음성만 |

장면 위험 찾기라는 방식 자체는 Site Coach, HazApp, KNOWRISK에 이미 있었다. 따라서 본 연구는 방식의 새로움이 아니라 **국내 법령·공식 자료 기반의 문장 단위 근거 체계, 그림 중심 설계 원칙, 앱 안 측정 도구의 조합**을 다룬다.

**검토의 한계.** 판정자 1명(판정자 간 일치도 없음), Google Play는 검색 화면 상위 약 30개만 확인, 앱을 설치하지 않음, 학술 검색은 KCI·RISS·Scopus 체계적 검색 전(웹 검색 + koreascience 원문 6편 + 해외 초록). 제출 전 학술 DB 검색을 다시 해야 한다.
