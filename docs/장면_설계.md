## 1. 장면 구성 원칙
- 장면 = 직접 그린 현장 그림 1장(글자 없음) + 위험 3~5곳 + **함정(안전한 곳) 1~2곳**
- 위험 하나 = 누를 영역 · 위험 종류 아이콘 · **위험한 모습 → 안전한 모습 두 장 그림** · 한 줄(15자 안팎) · 출처 id · 상태
- 흐름(장면 하나 2~4분): ① 장면 보기 → ② 위험 찾기(손가락) → ③ 찾을 때마다 두 장 그림 + 한 줄 → ④ 다 찾거나 "그만 찾기" → ⑤ 못 찾은 곳 보여 주기 → ⑥ 별 1~3 + 도감
- KYT 1라운드(현상 파악)를 혼자 하는 꼴. 대책은 "안전한 모습" 그림으로 보여 줌
- 함정: 이미 안전하게 된 곳(예: 덮개 고정·표시된 개구부). 누르면 "여긴 안전해요"(초록 체크 아님 — 회색 + 엄지) → 아무 데나 누르는 것을 막음

## 5. 그림 모드 흐름 (글 없이)
1. 첫 화면 큰 버튼 두 개: **그림 모드**(눈 + 손가락 그림) / **글 모드**(가 글자 그림). 기본은 그림 모드
2. 안내 = 손가락이 눌러 보이는 애니메이션, 장면 위 반짝이는 테두리 없음(답을 알려 주지 않게)
3. 찾음 → 두 장 그림이 옆으로 넘어감(위험한 모습 ✕ 회색 / 안전한 모습 ✓ 초록), 삽이 표정
4. 못 찾은 곳 → 장면 끝에 깜박이며 보여 줌
5. 스피커 버튼(선택): 한 줄을 소리로 읽음. 소리 없어도 이해되게 그림이 먼저
6. 점검(사전·사후)도 그림 판: 장면 한 장에서 위험 찾기 + 그림 보기 고르기 → **위험 인지율** 기록
