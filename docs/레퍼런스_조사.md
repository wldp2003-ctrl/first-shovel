# 레퍼런스 조사 (v13 "현장 위험 찾기")

> 조사일 2026-11-16. 목적: 교수님 피드백(현장 사진·직관적 위험 인지, 글 못 읽는 외국인, 게임 형식)에 맞는 설계 근거 찾기.
> 등급 규칙: 1~3등급만 앱 화면에, 4등급(논문)은 설계 근거로 문서에만, 5등급(뉴스·블로그)은 사실 근거로 쓰지 않음(존재 확인용으로만 적고 원자료를 따로 찾음).
> **이용 조건이 확인되지 않은 그림·사진은 앱에 넣지 않는다.**

## 1. 요약 — 레퍼런스에서 가져올 것

| 결론 | 근거 레퍼런스 |
|---|---|
| **장면 속 위험 지점을 찾는 형식**이 핵심. 위험 지점마다 "왜 위험 + 어떻게 막나" | SIF 고위험요인 포스터(공단), KYT 1라운드 "현상 파악", ITcon 2025 |
| **위험한 모습 ↔ 안전한 모습을 나란히** 보여 준다 | 서울시 무번역 그림책("지켰을 때와 안 지켰을 때 비교") |
| 글 대신 **스케치·픽토그램·사진**. 번역만으로는 부족 | IOSH·GCU 연구(Billy Hare) |
| 픽토그램은 **안전보건표지 모양 규칙**을 따르고 외국인 의견을 들어 만든다 | 고용노동부·공단 안전보건 픽토그램(2024) |
| 평가도 **그림으로** (글 읽기 능력이 점수에 섞이지 않게) | 그림 기반 평가 연구(JOE 2013 — 원문 미확인), ITcon 2025 Assessment 장면 |
| 짧게 자주 반복 | 공단 "위기탈출 안전보건" 앱 "작업 시작 전 10분", 학습 앱의 짧은 반복·연속 학습 방식 |
| 우리만의 자리: **신규 근로자 혼자, 글 없이, 장면에서 위험을 찾고, 찾은 비율이 기록되는 도구** | 위기탈출 앱(관리자용 교육 콘텐츠·일지)과 겹치지 않음 |
