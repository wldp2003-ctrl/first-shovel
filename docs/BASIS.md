# 첫 삽 — 게임 내용과 근거 (v10)

게임의 결과 카드와 현장 이벤트에 나오는 "무슨 작업 → 왜 위험 → 근거"를 한곳에 모은 표입니다. 내용은 `js/basis.js`에서 관리합니다.

- **법정**: 산업안전보건법, 산업안전보건기준에 관한 규칙(안전보건규칙)
- **표준**: KS, KCS 표준시방서
- **게임**: 이해를 돕기 위해 게임에서 단순화한 부분
