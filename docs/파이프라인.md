# 3D 제작 파이프라인 (v18, 0원)

3D 장면을 고치거나 에셋을 넣을 때의 순서입니다. 돈이 드는 API와 에셋은 쓰지 않습니다.
- 규칙: `docs/아트바이블.md` (재질 세트, 팔레트, 빛, 검수 기준)
- 출처: `docs/에셋_라이선스.md`, `data/media.json`
- 치수: `docs/모델_치수.md`

## 한눈에
```
원본(art/src/, 저장소에 안 넣음)              앱(www/)
─────────────────────────────                ──────────────────────────────
Kenney .glb  ─────────────┐
OpenGameArt .blend ─ blend-export.py ─ .glb ─┼─ import-cc0.mjs ─ assets/models/*.json
                                             │   (원래 색 버림 → 재질 키로 다시 입힘, m 단위)
Poly Haven 질감·HDRI ─ prep-textures.mjs ────┴─ assets/tex/*.webp, sky.hdr
three.js 예제 ─ vendor-addons.mjs ─────────────── vendor/addons/** (베벨, 후처리)

코드 모델: js/learn/models/worker.js(근로자), models/safety.js(안전 구조물), props3d.js(소품)
장면: js/learn/site3d.js(지도), scene3d.js(위험 찾기 7구역)
  └ render-scenes.mjs ─ assets/scenes/** (WebP) + data/prerender.json (누를 곳)
```

## 1. 원본 받기 (한 번)
- 받은 파일은 `art/src/<출처>/`에 둡니다. `.gitignore`에 있어서 저장소와 배포에 들어가지 않습니다.
- 받기 전에 페이지에서 라이선스를 확인합니다. CC0이 먼저이고, CC-BY도 됩니다. 그 밖의 라이선스는 쓰지 않습니다.
- 확인한 뒤 `docs/에셋_라이선스.md` 표에 한 줄, `data/media.json`에 한 항목을 넣습니다.

## 2. 모델 변환
- **`.blend`나 `.fbx` 원본**은 무료 Blender 휴대용판(`art/src/tools/blender-*/blender.exe`)으로 GLB로 바꿉니다.
  ```
  blender -b <원본.blend> --python tools/blend-export.py -- art/src/glb/<이름>.glb "<물체 이름>"
  ```
  - `'*'`를 주면 모든 메시를 내보냅니다. 뒤에 빼고 싶은 물체 이름을 붙입니다(`Plane.0*`처럼 앞부분만 써도 됩니다).
  - 면이 많으면 `DEC=0.3`처럼 줄일 비율을 환경 변수로 줍니다(굴착기는 0.3).
  - Blender는 도구로만 씁니다. Blender의 GPL은 만든 결과물에 적용되지 않습니다.
- **재질 다시 입히기**: `tools/import-cc0.mjs`의 `LIST`에 한 줄을 넣고 돌립니다.
  ```
  node tools/import-cc0.mjs --scan <이름>   # 색 무리(orange·yellow·gray…)와 면 수 보기
  node tools/import-cc0.mjs <이름>          # assets/models/<이름>.json 만들기
  ```
  - 면마다 원래 색(Kenney colormap, GLB 안 팔레트 그림, 재질 기본색 가운데 있는 것)을 읽어 색 무리로 나눕니다. 그다음 `map`에 적은 재질 키로 바꿉니다.
  - `fit`으로 길이나 높이를 m 단위로 맞추고, `rotY`로 방향을 돌립니다.
  - 결과는 base64 JSON이고, 모델 하나에 2~400KB입니다.
- **방향과 모양 확인**: `node tools/_v18_models.mjs 이름1,이름2` → 줄 세운 그림이 나옵니다. 빨간 막대가 +x 쪽입니다.
- 새 모델 이름은 `js/learn/materials.js`의 `MODELS`와 `sw.js`의 `CORE`에 넣습니다.

## 3. 질감·HDRI
- `node tools/prep-textures.mjs`를 돌립니다. Poly Haven 1k 질감을 받아 흑백 결(`_d`), 노멀(`_n`), 거칠기(`_r`) WebP로 바꿉니다. HDRI는 256×128 `.hdr`로 줄입니다.
- 색은 질감에서 가져오지 않습니다. 팔레트 토큰(`css/tokens.css`의 `--pbr-*`)이 정합니다.

## 4. 코드 모델
- **근로자**는 `makeWorker(THREE, M, { helmet, chinStrap, vest, boots, harness, hook, pose, ry })`로 만듭니다. 장면에서는 `person(K, x, z, { strap, shoes, hookW })`로 부르고, `hookW`는 고리를 건 곳의 장면 좌표입니다.
- **안전 구조물**(`models/safety.js`)은 지도(`site3d`)와 장면(`scene3d`)에서 같은 함수를 씁니다.

  | 함수 | 위험/안전을 가르는 옵션 |
  |---|---|
  | `guardrail` | `top`, `mid`, `toe` |
  | `opening` | `cover` |
  | `systemScaffold`, `deck` | `skip`(발판 뺄 칸), 그 칸만 `deck` |
  | `mobileTower` | `locked` |
  | `pipeSupport`, `shoring` | `bent`, `spliced` |

- **위험한 모습과 안전한 모습은 옵션 하나만 바꿉니다.** 위험마다 `hz(K, H, id, 누를곳, 위험한모습, 안전한모습, 가까이카메라)`를 씁니다. `id`는 `scenes.json`의 위험 id와 1:1입니다.

## 5. 렌더링
```
node tools/_v18_try.mjs <구역id> [out.png]       # 위험 찾기 장면 한 장 (빠른 확인)
node tools/_v18_map.mjs [구역번호|all] [out.png]   # 지도 / 구역 가까이
node tools/render-scenes.mjs tbm floor scaffold lifting equip pour hot   # 최종 미리 렌더링
```
- 실제 GPU(D3D11)로 렌더링합니다. 그림자 4096, MSAA 4×, SAO, 아주 약한 피사계 심도를 씁니다. `SW=1`이면 소프트웨어 렌더러로 바뀝니다(느리고 조금 거칩니다).
- 결과는 `assets/scenes/<id>/v*.webp`(찾기 장면), `<위험id>-bad/good.webp`(쌍), `zone.webp`, `map.webp`입니다. 누를 곳은 `data/prerender.json`에 적힙니다. `scenes.json`은 바꾸지 않습니다.

## 7. 배포
1. `node tools/build-pages.mjs` → `dist-pages/`. `sw.js`의 `CORE` 목록에 없는 파일이 있으면 멈춥니다.
2. 에셋이 바뀌면 `sw.js`의 `VERSION`을 올립니다(v18 = `cheotsap-v18`).
3. `dist-pages`에서 커밋하고 push합니다. 그다음 GitHub Pages가 열리는지 확인합니다.
