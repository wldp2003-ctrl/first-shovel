# 모델 치수 (v18)

3D 모델의 치수와 그 근거입니다. 1단위는 1m입니다.
- **근거 표기**: `data/sources.json`의 id(원문확인)나 기본서 쪽수를 씁니다.
- **"확인 필요"**: 원문으로 확인하지 못한 수치입니다. 보기에 자연스러운 값을 썼고, **교육 문장(레슨·카드·해설)에는 쓰지 않습니다.**
- 법령 조문 번호와 수치는 원문으로 확인한 것만 적습니다.
